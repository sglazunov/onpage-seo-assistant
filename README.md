# OnPage SEO Assistant

Браузерное расширение для быстрого технического и контентного SEO-аудита текущей страницы.
Chrome, Opera, Яндекс Браузер и другие Chromium-браузеры с поддержкой Manifest V3.

Аудит запускается локально, без аккаунтов, внешних API и отправки HTML куда-либо.

## Возможности

- **Meta** — title, description, robots, viewport, canonical, hreflang, charset, favicon,
  сводный блок «Индексируемость» (meta robots + googlebot + yandex).
- **Заголовки** — дерево H1–H6, пропущенные уровни, дубли, пустые и скрытые заголовки.
- **Ссылки** — деление на внутренние/внешние/mail/tel/anchor/javascript, `rel` (nofollow,
  sponsored, ugc), `target="_blank"` без `noopener`, ссылки на http с https-страницы,
  проверка HTTP-статусов с прогрессом и ограничением параллелизма.
- **Изображения** — отсутствующий `alt` отличается от декоративного `alt=""`, размеры,
  lazy loading выше и ниже первого экрана, srcset, незагрузившиеся файлы, доступность SVG.
- **Schema** — JSON-LD с форматированием и проверкой синтаксиса, Microdata, RDFa, типы сущностей.
- **Social** — Open Graph и Twitter Cards с предпросмотром карточки.
- **Контент** — объём текста, абзацы, списки, таблицы, частотность слов, биграммы и триграммы,
  проверка вхождения ключевой фразы по зонам (URL, Title, Description, H1, H2, первый абзац, текст).
- **Техническое** — HTTPS, mixed content, размер DOM, блокирующие скрипты, ошибки JavaScript,
  iframe, а по кнопке — robots.txt, sitemap.xml, X-Robots-Tag и цепочка редиректов.
- **Подсветка на странице** — прокрутка к элементу, цветная рамка по категории, Esc снимает.
- **Экспорт** — JSON, CSV, Markdown, автономный HTML-отчёт, копирование сводки.
- **История аудитов**, настраиваемые пороги, отключаемые правила, тёмная тема, русский и английский.

## Установка (Developer Mode)

```bash
npm install
npm run build
```

Затем:

1. Chrome: `chrome://extensions` · Opera: `opera://extensions` · Яндекс Браузер: `browser://tune`
2. Включить «Режим разработчика».
3. «Загрузить распакованное расширение» → выбрать папку **`dist`** (не корень проекта).

Готовый архив для магазина: `npm run zip` → `release/onpage-seo-assistant-<version>.zip`.

## Как пользоваться

Откройте любую обычную страницу и нажмите на иконку расширения — аудит стартует
автоматически. Кнопка ↻ перезапускает его после изменения DOM: это важно для SPA на
React или Angular, где контент появляется уже после загрузки.

Сетевые проверки (HTTP-статусы ссылок, robots.txt, sitemap.xml, заголовки) запускаются
отдельными кнопками и в этот момент запрашивают разрешение на доступ к сайтам.

## Про SEO Score

Score — внутренняя диагностическая оценка расширения по формуле `100 − сумма штрафов`.
**Это не прогноз позиции в Google или Яндексе.** Пороговые значения длин (title,
description, alt) — ориентир, а не правило поисковых систем; они меняются в настройках,
а любое правило можно отключить.

Разбивка: общий балл, три группы (Technical / Content / Social) и девять весовых
категорий. Веса и штрафы описаны в `src/core/scoring/weights.ts`.

## Приватность

Расширение не собирает пароли, cookie, содержимое полей ввода и историю посещений,
не загружает сторонний код и не отправляет HTML страницы на сервер. Отчёты хранятся
локально в `chrome.storage.local`. Подробности — в [PRIVACY.md](PRIVACY.md).

При установке запрашиваются только `activeTab`, `scripting`, `storage`, `downloads`.
Доступ к сайтам опциональный и запрашивается лишь при явном запуске сетевой проверки.

### Известные ограничения

- CSS `background-image` не анализируются — только `<img>` и inline `<svg>`.
- Содержимое `iframe` не входит в аудит (расширение помечает это явно).
- Таблицы ссылок и изображений показывают до 500 и 300 строк; полные данные — в экспорте.
- Проверка HTTP-статусов различает `CORS blocked`, `Timeout` и `Network error` и **не**
  считает такие ссылки битыми — понижает Score только реальный ответ 4xx/5xx.

Результаты приёмочного прогона и текущий статус релиза — в
